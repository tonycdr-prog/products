# Marketing plan

## Distribution channels
Reddit r/UKPersonalFinance, SEO for HMRC expense queries, accountant newsletters, Facebook sole trader groups, Product Hunt makers.

## First-week launch tactics
1. Reply helpfully to the source Reddit thread with a free version and ask for blunt feedback.
2. Publish a short SEO explainer targeting the exact anxiety phrase from the source post.
3. Offer 20 free personalised reviews in exchange for testimonials.
4. Add a one-question exit survey: 'What would make this worth paying for?'
5. Ship one improvement per day from user feedback and post a public changelog.
