# Marketing Plan — ScopeGuard

## First-week channels
1. Reddit comments/posts in relevant communities with a useful checklist, not spam.
2. LinkedIn founder/operator post showing before/after workflow.
3. UK freelancer/bookkeeper/housing Facebook groups where allowed.
4. SEO landing page targeting exact pain query.
5. Direct outreach to 20 niche advisors/community organisers.

## First 3 launch moves
- Publish the calculator as a free tool.
- Ask 10 target users to paste one real example and compare output.
- Add Stripe payment link only after 3+ people request saved/export features.
