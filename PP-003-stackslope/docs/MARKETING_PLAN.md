# StackSlope Marketing Plan

## Landing page headline
Know when Supabase stops being “basically free”.

## Three benefits
- Spot pricing cliffs before demo traffic or project sprawl turns into a surprise bill.
- Compare managed Supabase-style costs against a realistic self-hosting budget.
- Copy a plain-English report with next actions for consolidation, alerts, and migration trials.

## CTA copy
Run the free pricing-cliff calculator → Save your first scenario → Reserve early access for weekly usage checks.

## Primary distribution channel
Hacker News follow-up on Supabase/self-hosting/pricing threads, with a concise comment linking the free calculator and asking for edge-case inputs.

## First-week plan
1. Ship static calculator to the product shelf/GitHub Pages.
2. Add a short teardown post: “When does a side-project Supabase stack stop being free?”
3. Comment only where the pain is already active; do not spam generic SaaS communities.
4. Collect five real portfolios manually and use them to tune the risk thresholds.
5. Add Buttondown/ConvertKit capture once Tony picks the list tool.
